隐私政策

本隐私政策说明 GitNest（以下简称「本应用」）在收集、使用、存储和保护用户信息方面的做法。请仔细阅读。本应用为纯客户端桌面工具，不依赖任何自建后端服务器，因此数据处理范围极其有限。

一、信息收集

本应用不主动收集、不上传任何用户数据到开发者或任何第三方服务器。具体而言：

  1. 个人账户信息：本应用不会采集您的姓名、邮箱、手机号等个人身份信息。
  2. 使用行为数据：本应用无遥测（telemetry）、无用户行为分析、无崩溃上报。
  3. 设备信息：本应用不采集设备指纹、IP 地址、地理位置等信息。

本应用运行过程中产生的所有数据均保存在您本机的用户目录下，不会离开您的设备。

二、GitHub Token 的处理

本应用需要访问 GitHub 仓库，因此会获取一个 GitHub Personal Access Token（或通过 OAuth 流程获取的访问令牌，以下统称「Token」）：

  1. 获取方式：由您主动粘贴 Token，或通过 GitHub 官方 OAuth 流程（设备码 / 网页授权）获取，Token 由 GitHub 直接发放。
  2. 存储方式：Token 仅保存在本机用户目录的配置文件中，并使用操作系统级凭据加密：
    • Windows：DPAPI（数据保护 API）
    • macOS：Keychain（钥匙串）
    • Linux：libsecret / 桌面环境密钥环
    加密后的存储前缀为 enc:v1:，无法在其他设备或其他用户账户下解密。
  3. 使用方式：Token 仅用于调用 GitHub REST API（api.github.com）以及本地 Git 操作的远程鉴权（推送 / 拉取时注入到远程 URL，使用后即丢弃，不写入磁盘明文）。
  4. 共享情况：Token 绝不会被发送给开发者或任何第三方，仅直连 GitHub 官方服务。
  5. 删除方式：在应用内退出登录即清除本地 Token；或手动删除配置目录（见下文）即可彻底清除。您也可随时在 GitHub 账户设置中吊销该 Token。

三、网络请求去向

本应用发起的所有网络请求均直连 GitHub 官方域名：

  • api.github.com —— GitHub REST API
  • github.com —— OAuth 授权与代码下载

其中 Web OAuth 的回调地址为本机回环地址 http://127.0.0.1:8765/callback，仅在授权期间临时监听，授权完成后立即关闭端口，不对外暴露。

四、本地文件访问

  • 当您选择「导入本地仓库」或「下载并初始化」时，本应用会读写您指定目录中的文件与 Git 元数据（.git）。
  • 这些操作完全在本机进行，文件内容不会被上传。
  • 本应用不会读取或访问您未明确指定的目录。

五、本地数据存储位置与清除

配置文件（含加密后的 Token、仓库列表、偏好设置）保存在：

  • Windows：%APPDATA%\gitnest\
  • macOS：~/Library/Application Support/gitnest/
  • Linux：~/.config/gitnest/

卸载本应用不会自动删除这些配置。如需彻底清除，请手动删除上述目录。

六、未成年人保护

本应用面向开发者群体，不专门面向未成年人。若您是未成年人，请在监护人指导下使用。

七、政策更新

本政策可能随功能变更而更新，更新后将在应用内（帮助 → 隐私政策）及本文件同步发布，重大变更将通过显著方式告知。
